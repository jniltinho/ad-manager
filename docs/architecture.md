## Components

```
main.go → cmd/ (Cobra)
            ├─ user, group, ou, computer, policy   management from the CLI
            ├─ export, import                       CSV
            ├─ migrate preflight|inventory|diff     cutover support
            ├─ server                               web panel
            └─ mcp                                  MCP server (stdio)
internal/ad        the only layer that talks to AD (go-ldap v3)
internal/server    Echo v5 JSON API + embedded SPA (web/dist via go:embed)
internal/audit     JSON lines per change (log/slog)
internal/config    config.toml + AD_* variables
frontend/          Vue 3 + Tailwind 4, built with Vite+ (vp) → web/dist
```

CLI, panel and MCP call the same functions in `internal/ad`, so the behavior is identical
in all three (parity required by the `directory-management` spec).

## Authentication and session

1. The operator logs in with `user`, `user@example.local` or `EXAMPLE\user`.
2. The server performs an **LDAPS bind** with those credentials. 5 failures in 5 minutes from the same IP → HTTP 429.
3. Authorization: the operator's `tokenGroups` must contain `<domain SID>-512` (*Domain Admins*,
   including nested). By SID, not by name — renaming the group does not open a hole.
4. Session: random 256-bit id in an `HttpOnly; Secure; SameSite=Strict` cookie. The password is kept
   **only in the process memory** to redo the bind on each request; it expires after 30 min of inactivity.
   Restarting the service drops all sessions.
5. Each request opens its own LDAPS connection with the operator's identity: AD applies the operator's
   ACLs and the DC's security log shows who made each change.

The panel refuses to start over HTTP outside loopback. Behind Nginx/Caddy with TLS, listen on
`127.0.0.1` and use `trust_proxy = true` (the real IP comes from `X-Forwarded-For`).

## Connecting to AD

| Situation | URL | Bind |
|---|---|---|
| Samba (production, lab, Docker) | `ldaps://host` | simple (inside TLS) |
| Legacy DC without a certificate (Windows 2008 `old-dc`) | `ldap://10.0.0.10` | NTLM — the password does not travel in clear text |

Without TLS, any password operation is refused (`unicodePwd` requires an encrypted connection). Samba's
self-generated certificate has a negative serial number; `go.mod` sets `godebug x509negativeserial=1`
to accept it. In production prefer your own certificate and `ad.ca_file`.

## Protections on the server (not just in the UI)

- Objects with RID < 1000 (Administrator, krbtgt, Guest, Domain Admins…), DC accounts and the operator's own
  account: cannot be deleted/disabled; DCs cannot be moved either.
- An OU can only be removed when empty; `Domain Controllers` never.
- CSV import only creates and updates; it never deletes objects or removes members.
- Passwords never go to logs, audit or responses (except those generated by the import, returned only once).

## Audit

`audit.log` (JSON, one line per action): `time, actor, ip, action, target, result`. The CLI writes with
`ip = "cli"` and MCP with `ip = "mcp"`.

```json
{"time":"2026-10-17T15:20:19-03:00","level":"INFO","msg":"audit","actor":"administrator","ip":"cli","action":"user.create","target":"panel.test","result":"ok"}
```
